# 麻雀点棒

スマホ1台で四麻・三麻の点棒を管理する静的Webアプリ。
公開先: https://ei2537.github.io/mahjong/

## モード

入口から4つのモードを選ぶ。対局の記録は互いに独立して保存する。旧版の四麻の対局記録は「対局をまとめて管理」から再開できる。

- `#game`: 親決め・開門・点数計算・点棒精算・局進行をまとめて管理。
- `#wall`: 親決めと山の案内だけ。親を指定し直して別の局の開門も調べられる。
- `#calculator`: 対局登録なしで牌から計算。人数・場風・本場・席・ルールを指定して支払額を表示する。点棒やリーチ棒は移動しない。牌入力の途中状態も保存する。
- `#points`: 点棒の受け渡し、リーチ供託、供託の回収、順位だけを記録。親決めや局の自動進行は行わない。

## 使い方

1. スマホを置く側から、四麻は手前・右・向かい・左、三麻は手前・右・左の順に名前を入力する。
2. 起家をサイコロの2度振りで決定する。実物の出目入力や親の直接指定も可能。
3. 各局の親が2個を1度振り、開門する山・幢数・王牌・ドラ表示牌・配牌の案内を見る。
4. 対局中はリーチを登録。和了時は支払点の直接入力、または牌から計算を選ぶ。
5. 全員の増減を確認して精算する。流局時はテンパイ者を選ぶ。

牌入力では、和了牌を除いた手牌・和了牌・副露／槓・ドラ表示牌・和了状況を入力する。副露は鳴いた順に相手も指定する。リーチ時は裏ドラ表示牌も入力する。表示する役・翻・符・支払点を確認してから精算する。

## 採用ルール

- 四麻・三麻、半荘／東風戦。四麻は25,000点、三麻は35,000点開始（変更可能）。四麻は東4局・南4局、三麻は東3局・南3局まで。
- 赤5各色1枚、喰いタン、切り上げ満貫、数え役満、ダブル役満は開始時に設定できる。
- 本場: 四麻はロン300点、ツモ各家100点。三麻は同じ加点、またはロン1,000点・各500点を選択。リーチ1,000点を供託へ移す。
- 通常流局のノーテン罰符（四麻3,000点・三麻2,000点）を自動分配。親の和了・テンパイは連荘。途中流局は連荘し、本場を増やす。
- 複数ロンは四麻3人・三麻2人まで。同じ放銃者への全員分をまとめて精算。供託は放銃者からツモ順が最も近い和了者に渡す。三家和を流局にする卓は途中流局で登録する。
- 役満の複合・包に対応。包の判定に必要な副露順と鳴いた相手は正しく指定する。
- 規定局数の後は終了・延長を選択。アガリ止めは局の合間にメニューから終了。トビの自動終了は行わない。
- 同点は同順位。残った供託は終了時にトップへ（同点は起家からの順）。ウマ・オカは計算しない。
- 振聴、一発の成立、鳴きや特殊和了の成立条件は卓上で確認する。チョンボ・流し満貫など卓独自の精算は、直接入力／点数調整を使う。

### 三麻の牌・山・ツモ払い

- 萬子2〜8・赤5萬を使用しない108枚。チーなし。赤5筒・赤5索は各1枚。
- 北抜きあり／なしを選択可能。抜いた北は1枚1翻、表・裏ドラ表示が西ならその枚数分も追加する。役のない手に抜きドラだけを加えても和了れない。北は手牌にも使える。
- 1萬表示のドラは9萬、9萬表示のドラは1萬。自風は東・南・西の3席。
- 山の案内は1人18幢×2段、3つの山を積む方式を採用する。北抜きありは補充用8枚を含む王牌9幢・18枚、表示牌は開門側から5幢目の上段。北抜きなしは王牌7幢・表示3幢目。
- 北抜きでの補充を嶺上開花として扱わない。他家の抜きは一発・地和・ダブルリーチを消す扱い。成立状況は卓上で確認し入力する。
- 「ツモ損あり」: 四麻と同じ額を実在する2人だけが払う。
- 「北家分を折半」: 不在の北家の四麻での支払額を2人に半分ずつ加算し、各100点単位で切り上げる。例: 子の20符3翻は通常親1,300・子700点、折半で親1,700・子1,100点。役満の包は責任払いを優先する。

直接入力の支払点には本場・供託を含めない。三麻の直接入力では、選んだツモ払いで各家が実際に払う金額を入れる（折半への自動変換はしない）。本場・供託はアプリが加算する。点数調整時にも持ち点と供託の合計を維持する。

## 保存・オフライン

外部API、外部フォント、CDN、アカウント登録は不要。点数計算ライブラリも同梱する。対局はブラウザ内のlocalStorageに自動保存し、80操作まで戻せる。

iPhoneは通信できる場所でSafariから「共有 → ホーム画面に追加」を選ぶ。追加したアイコンから開き直し、メニューの「オフライン利用」で「オフライン準備完了」を確認する。実際に機内モード＋Wi-Fiオフで、閉じて開き直すテストをする。ブラウザのサイトデータを消すと記録・保存済みファイルも消える。

Service Workerは `/mahjong/` だけを扱い、`/card/` のキャッシュ・対局データとは独立している。

## 開発・検証

ビルド不要。任意の静的HTTPサーバーからルートを配信する。Service WorkerはHTTPSまたはlocalhostが必要。

```sh
node --test mahjong/tests/*.test.mjs
```

四麻・三麻の親・局・連荘、本場・供託、複数ロン、流局、点棒総数、北抜き・表示牌・ツモ損・折半・包の計算、単独の点棒移動、オフラインの依存ファイル網羅・起動・修復を検証する。

将来の更新では `index.html` / `app.mjs` / `offline.mjs` / `sw.js` のバージョンと、Service Workerの保存対象一覧を合わせて更新する。
