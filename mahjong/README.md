# 麻雀点棒

スマホ1台で4人打ちリーチ麻雀の点棒を管理する静的Webアプリ。
公開先: https://ei2537.github.io/mahjong/

## 使い方

1. スマホを置く側から、手前・右・向かい・左の順に名前を入力する。
2. 起家をサイコロの2度振りで決定する。実物の出目入力や親の直接指定も可能。
3. 各局の親が2個を1度振り、開門する山・幢数・王牌・ドラ表示牌・配牌の案内を見る。
4. 対局中はリーチを登録。和了時は支払点の直接入力、または牌から計算を選ぶ。
5. 全員の増減を確認して精算する。流局時はテンパイ者を選ぶ。

牌入力では、和了牌を除いた手牌・和了牌・副露／槓・ドラ表示牌・和了状況を入力する。副露は鳴いた順に相手も指定する。リーチ時は裏ドラ表示牌も入力する。表示する役・翻・符・支払点を確認してから精算する。

## 採用ルール

- 4人打ち、半荘／東風戦。開始25,000点（変更可能）。
- 赤5各色1枚、喰いタン、切り上げ満貫、数え役満、ダブル役満は開始時に設定できる。
- 本場: ロンは300点、ツモは各家100点。リーチ1,000点を供託へ移す。
- 通常流局のノーテン罰符3,000点を自動分配。親の和了・テンパイは連荘。途中流局は連荘し、本場を増やす。
- 複数ロンは3人まで。同じ放銃者への全員分をまとめて精算。供託は放銃者からツモ順が最も近い和了者に渡す。三家和を流局にする卓は途中流局で登録する。
- 役満の複合・包に対応。包の判定に必要な副露順と鳴いた相手は正しく指定する。
- 規定局数の後は終了・延長を選択。アガリ止めは局の合間にメニューから終了。トビの自動終了は行わない。
- 同点は同順位。残った供託は終了時にトップへ（同点は起家からの順）。ウマ・オカは計算しない。
- 振聴、一発の成立、鳴きや特殊和了の成立条件は卓上で確認する。チョンボ・流し満貫など卓独自の精算は、直接入力／点数調整を使う。

直接入力の支払点には本場・供託を含めない。本場・供託はアプリが加算する。点数調整時にも持ち点と供託の合計を維持する。

## 保存・オフライン

外部API、外部フォント、CDN、アカウント登録は不要。点数計算ライブラリも同梱する。対局はブラウザ内のlocalStorageに自動保存し、80操作まで戻せる。

iPhoneは通信できる場所でSafariから「共有 → ホーム画面に追加」を選ぶ。追加したアイコンから開き直し、メニューの「オフライン利用」で「オフライン準備完了」を確認する。実際に機内モード＋Wi-Fiオフで、閉じて開き直すテストをする。ブラウザのサイトデータを消すと記録・保存済みファイルも消える。

Service Workerは `/mahjong/` だけを扱い、`/card/` のキャッシュ・対局データとは独立している。

## 開発・検証

ビルド不要。任意の静的HTTPサーバーからルートを配信する。Service WorkerはHTTPSまたはlocalhostが必要。

```sh
node --test mahjong/tests/*.test.mjs
```

親・局・連荘、本場・供託、複数ロン、流局、点棒総数、牌計算、オフラインの依存ファイル網羅・起動・修復を検証する。

将来の更新では `index.html` / `app.mjs` / `offline.mjs` / `sw.js` のバージョンと、Service Workerの保存対象一覧を合わせて更新する。
