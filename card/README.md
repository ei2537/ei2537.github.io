# ポーカーチップ

スマホ1台で全員のチップを管理する、依存ライブラリ・サーバー不要の静的サイトです。

- テキサスホールデム専用（2〜10人、ノーリミット）
- ベット中は持ち点・ポット・全アクションをスマホ1画面に表示
- 画面全体を使う手番交代アニメーションと、ポットへのチップ投入演出
- アクションごとのⓘで、数値の変化・相手の選択肢・有利な点やリスクを確認
- 設定から説明ボタンの表示・非表示を変更し、ブラウザに保存
- 支払い差額・最低レイズ額の計算
- オールイン、サイドポット、引き分け、余剰ベットの返却
- ディーラー交代、チップ0人のスキップ、勝負間のチップ追加
- ブラウザへの自動保存と60操作の取り消し、同じブラウザ内の別タブとの同期

カードと勝敗判定は手元のトランプで行います。ベットはノーリミット、チップは1枚単位。ブラインドは固定です。引き分けの余りはディーラーの左から時計回りに配分します。インフォメーションを開いてもアクションは実行されません。相手への影響は、その時点のベット額とレイズの権利に基づきます。

全員のチップ・履歴・ショーダウンの長いリストは、別画面または一覧内で表示します。ベット中のメイン画面はスクロールしません。320×568、375×667、390×844の表示で確認しています。端末の「視差効果を減らす」等の設定に応じて演出を抑えます。

## ファイル

- `index.html` / `style.css`: 画面とレスポンシブ表示
- `app.mjs`: 画面操作・保存・取り消し
- `engine.mjs`: ブラウザから独立したチップ計算と進行
- `presentation.mjs`: アクション結果のプレビュー、相手の選択肢、チップの表示
- `tests/engine.test.mjs`: 金額保存、ベットの権利、サイドポットなどのテスト
- `tests/presentation.test.mjs`: 説明の数値・相手の行動権利・旧データ移行のテスト

ビルドは不要です。リポジトリのルートをGitHub Pagesで公開すると `/card/` で動作します。ローカルではHTTPサーバーを使ってください（ES Modulesのため、HTMLファイルの直接起動には対応しません）。

```sh
node --test card/tests/*.test.mjs
python3 -m http.server 8000
```

`http://localhost:8000/card/` を開きます。

保存は `localStorage` の `poker-chips:v1` に行い、説明ボタン設定は `poker-chips:v1:preferences` に保存します。同じ端末・ブラウザでのみ再開できます。以前の5枚ポーカーの保存は、投入済みチップを各人に返却してホールデムの開始前へ移行します。既存のホールデムの途中記録はそのまま再開します。プライベートブラウズの終了やサイトデータ削除で記録は消えます。外部のフォント・スクリプト・通信APIは使用しません。

参考: [PokerStarsのポーカールール](https://www.pokerstars.com/poker/games/rules/)、[Poker TDAルール](https://www.pokertda.com/poker-tda-rules/)。
